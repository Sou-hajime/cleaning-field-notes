# まちの清掃日報

スマートフォンで清掃の日時・人数・ゴミ袋数と写真を記録し、全30回の作業日報を作成するWebアプリです。

## メニューと使い方

- **日報一覧**：現場を選び、1〜30回の記録と提出用帳票を確認します。
- **現場で記録**：選択した現場の次の未完了回を入力します。現場が未登録なら、その理由と登録ボタンを表示し、このタブにとどまります。
- **新しい現場を登録**：清掃場所・作業所名・実施期間を最初に一度登録します。登録後は、その現場の第1回の日報入力に進みます。

登録済み現場の情報を変更するときは、一覧の「現場の情報を編集」を使います。新規登録フォームは常に新しい現場用で、登録済みの現場を上書きしません。

## 日報と帳票

作業日、開始・終了時刻、作業者数、指導者数、ゴミ袋数と、作業状況・ごみ袋の2種類の写真を保存できます。写真は長辺1600px以内のJPEGに変換し、縦横比を保って配置します。下書き保存と再開、保存済み日報の修正に対応します。

頭紙は第1〜15回と第16〜30回の2ページ、各回の日報は1ページです。頭紙・各回の日報・一式をブラウザで確認し、印刷またはPDFに保存できます。印刷はA4縦、倍率100%、ヘッダー・フッターなしを推奨します。保存済み日報のみを頭紙と提出用一式に含めます。元Excelへの直接書き込みは行いません。

## GitHub Pages 公開デモ

`docs/` をGitHub Pagesの公開元に設定すると、ログインなしで動作確認できます。公開デモの記録・写真は、利用したブラウザのIndexedDBに保存します。サーバーへのアップロードや端末間の同期は行いません。ブラウザのデータを削除すると記録も消えます。

Service Workerが必要なため、HTTPSまたはlocalhostで利用してください。プライベートブラウズや端末の設定で保存が制限される場合は、通常モードのSafari・Chromeで開いてください。公開するのはプログラムだけで、実際の作業記録・写真・秘密情報は含みません。

## 開発

Node.js 20以降を使用します。追加パッケージは不要です。

```bash
npm run build
npm test
```

`src/ui.html` が共通画面、`src/reports.js` が帳票、`src/server.js` が保存・検証処理です。`src/demo-storage.js` が公開デモ専用の端末内保存を担当します。`scripts/build-demo.mjs` が `docs/index.html` と `docs/sw.js` を生成します。

共用サーバー版ではCloudflare WorkersとR2のBUCKETバインディングを利用します。サーバー版を匿名で公開する場合は、現場ごとのアクセス制御を追加する必要があります。公開デモは端末内保存のため、他の閲覧者の記録を読み書きしません。

## 検証

現場未登録時にタブが変わらないこと、新規登録と既存編集の分離、GitHub Pagesのパス、写真保存、再読込、同時更新の競合、期間・人数の入力検証、下書き除外、帳票ページ構成、HTMLエスケープを確認しています。
